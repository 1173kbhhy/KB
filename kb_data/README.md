# 本地知识库使用说明

本目录是「Ollama 本地聊天」的**私有知识库**。开启顶栏「知识库」开关后，聊天时会先用这里的内容做语义检索，
再让本地 Qwen3-8B 作答并标注来源。所有数据都在本机，不上传任何云端。

## 目录约定

```
kb_data/
├── README.md                    本说明
├── 01-上午-综合知识/            上午选择题知识点（协议、概念、计算类）
├── 02-下午-案例分析/            下午案例分析（拓扑、配置、排错）
├── 03-错题本/                   做错的题、易混点
└── 04-真题高频考点/             你统计的 2023–2026 真题高频考点表
```

> 文件夹怎么分都行，检索不看目录层级，只看文件内容。上面的分法只是建议。

## 如何加入资料

两种方式，效果一样：

1. **直接放文件**：把 `.md` / `.txt` / `.pdf` 丢进任意子目录，下一次启动软件会自动索引。
2. **点「＋加入文档」**：在左侧栏 → 更新数据库，选单个文件即时入库（支持 PDF）。

索引是**按内容去重**的，同一份文件重复放入不会重复（但修改后请重新加入，旧分块会保留）。

## 检索原理（简单版）

- 启动或入库时，文件被切成约 600 字的小块；
- 每块用 `nomic-embed-text` 模型转成向量，存进本地 Qdrant 向量库；
- 你提问时，问题也被转成向量，找出最相近的几块，作为「参考资料」塞进系统提示；
- 模型优先依据这些资料作答，并在回复里标注来源文件名。

## 写作建议（影响检索质量）

- **一个知识点一个文件**，文件名即主题（如 `VLAN-Trunk-封装协议.md`）。
- 多用**小标题和短句**，方便被切成干净的小块。
- 概念、命令、配置片段分开放，不要和大段闲聊混在一起。
- 数字、命令、协议号要准确，模型会原样引用。
- PDF 若是扫描件（图片），当前版本读不到文字，请转成可复制文本的 PDF 或 .md。

## 支持的文件

| 格式 | 说明 |
|------|------|
| `.md`  | 首选，Markdown，分块效果最好 |
| `.txt` | 纯文本，直接入库 |
| `.pdf` | 需已装 `pymupdf4llm`（已装在 venv 里）；尽量用文字版 PDF |

把你的真题笔记、错题、老师给的资料按上面分类放进来，对话时打开「知识库」开关即可。
